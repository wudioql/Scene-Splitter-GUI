PySceneDetect 视频分割器 —— 快速上手（Windows）
================================================

【第一次使用】
  1. 安装 Python 3.9 及以上（实测至 3.14）：https://www.python.org/downloads/windows/
     安装时务必勾选 "Add python.exe to PATH"。
  2. 双击「安装依赖.bat」，等它跑完（会自动装 PySide6、PySceneDetect、ffmpeg 等）。
  3. 双击「启动.bat」即可。

关于项目虚拟环境（.venv，推荐）：
  安装依赖.bat 在没有 .venv 时会询问是否创建（直接回车即创建，需约一分钟）。
  创建后，所有脚本（启动 / 调试启动 / 诊断 / 打包）都会自动使用 .venv 里的 Python，
  依赖装在项目目录内，不影响系统 Python。删除 .venv 文件夹即回到系统 Python 模式。
  如果安装时问"是否改用系统 Python 继续安装"：说明 .venv 没建起来，直接回车=取消（推荐），
  只有输入 y 才会装进系统 Python。如果脚本提示 .venv 已损坏：删掉整个 .venv 文件夹，
  重跑一遍「安装依赖.bat」即可重建。

【如果 启动.bat 一闪而过】
  1. 双击「诊断.bat」，会逐项检查 Python / 依赖 / ffmpeg / 图形环境；
  2. 双击「调试启动.bat」，控制台会保留，报错信息能完整看到；
  3. 启动失败时程序也会弹窗提示，并把详情写进「启动日志.txt」。

【推荐流程：先预览，再分割】
  1. 选视频（可直接把文件拖进窗口）→ 设置检测算法和分段限制；
  2. 点「① 预览分段」——这一步只做检测，不产生任何文件；
     预览表会列出最终会切成哪几段、每段多长、输出文件叫什么；
  3. 选中某一段，下方会显示该段的 首/中/尾 画面，用来确认切点是否合适；
     不满意可以「删除选中段」或「与上一段合并」（播放器下方也有这两个按钮，看完直接点），也可以改参数后重新预览
     （改完参数程序会自动提示需要重新预览，不会用旧结果直接切）；
  4. 满意后点「② 开始分割」，输出的就是刚才预览的那一份。
  只想看清单不切视频：点「仅检测并导出报告」。

【想做免安装 EXE】
  双击「build_exe.bat」，完成后把 dist\PySceneDetect视频分割器\ 整个目录拷给他人即可。

【其它】
  · 「批量处理」页可一次处理多个视频或整个文件夹（参数沿用视频分割页）。
  · 结果在「结果与日志」页查看，双击某行可播放该片段。
  · 最常用的三个调节：
      - 想切得更多：把「检测阈值」调小（如 20），并把「内部最短场景(帧)」设为 0；
      - 想限制每段长度：「分段长度限制」里填最短/最长时长(秒) 或 最少/最多帧数；
      - 要帧级精确的切片起点：输出设置里选「重编码 H.264」（否则按关键帧切，速度极快）。
